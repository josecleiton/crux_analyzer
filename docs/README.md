# crux_analyzer documentation

crux_analyzer is a **semantic analyzer** for Rust + [Crux](https://redbadger.github.io/crux/)
applications: it statically extracts each Core's state machines — states,
transitions, triggering events and requested effects — into an intermediate
model, and turns that model into living documentation (interactive web UI,
Mermaid/Markdown docs).

## The elevator pitch

Crux apps are state machines by construction: a `Model`, an `Event` enum, and
an `update` function that moves the model between states and requests
`Effect`s. That structure is documentation — but it lives scattered across
`match` arms, guards and helper functions, and it drifts the moment nobody is
looking.

crux_analyzer reads the source (via the `syn` AST — it never depends on Crux
itself), reconstructs the machines, and emits a small JSON model. Everything
else — the web UI, the doc generators, future clients (VS Code extension,
PlantUML/HTML) — consumes only that model. Run it with `--watch` and the
documentation stays alive as the code changes.
